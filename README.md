# ✋ AirDraw - Real-Time Hand Tracking Drawing App

Draw in the air using just your hand and webcam! AirDraw uses MediaPipe hand tracking to let you draw, move, and create art without touching your screen.

## ✨ Features

- ☝️ **Draw** — Point your index finger to draw on screen
- 🤏 **Move** — Pinch to grab and move any stroke
- ✋ **Idle** — Open hand to stop drawing
- 🎨 10 vibrant neon colors to choose from
- 📏 Adjustable brush thickness (2px – 30px)
- ✨ Glow effect with adjustable intensity
- ↩️ Undo last stroke
- 🗑️ Clear canvas
- 💾 Download your drawing as PNG
- 🖥️ Mirror BG / Dark BG toggle mode
- ⚡ Runs entirely in the browser — no install needed

## 🔧 How to Use

1. Open the app in your browser
2. Allow **camera access** when prompted
3. Wait for MediaPipe to load
4. Use your hand gestures to draw:
   - ☝️ **Index finger up** → Draw mode
   - 🤏 **Pinch (thumb + index)** → Move a stroke
   - ✋ **Open hand** → Idle / stop drawing
5. Use the right panel to change colors, thickness, and glow
6. Download your artwork anytime!

- A modern browser (Chrome recommended)
